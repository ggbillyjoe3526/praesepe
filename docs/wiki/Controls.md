# Controls

Keyboard and mouse. The same list is in the game: Esc, then **Settings**, then **Controls**. Keys can't be changed
yet.

## Flying

| Key | What it does |
| --- | --- |
| W / S | Speed up / slow down. With flight assist on, let go and the ship holds its speed |
| A / D | Slide left / right |
| Space / Ctrl (or C) | Slide up / down |
| Mouse | Steer (nose up, down, left and right). The stick eases back to the centre when you stop |
| Q / E | Roll left / right |
| R | Roll level: rolls round the nose until the nearest planet or moon is below you and its horizon is level. Q or E stops it ([Flying](Flying#rolling-level)) |
| Z | Flight assist on or off ([Flying](Flying#flight-assist)) |
| X | Full stop (turns flight assist back on). In cruise, drops out and stops |

## Travel

| Key | What it does |
| --- | --- |
| F | Cruise drive: aim at a place and press F to fly there, or press it aimed at nothing to cruise where the nose points. F again drops out ([Cruise Drive](Cruise-Drive)) |
| O | Enter orbit once you're close to a planet's or moon's orbit line. O again, or any thrust key, leaves ([Orbit](Orbit)) |
| G | Dock at the station or land at the base when the HUD offers it. G on the way takes the controls back; G again undocks or takes off ([Docking and Landing](Docking-and-Landing)) |

## Nav computer

| Key | What it does |
| --- | --- |
| Tab | Open or close the nav computer ([Nav Computer](Nav-Computer)) |
| Up / Down | Pick a place |
| Left / Right | Pick how to arrive: dock, land, orbit or stop nearby |
| Enter | Go now |
| Shift+Enter | Add to the plan |
| P | Pause or resume the plan |
| Backspace | Clear the plan |

While it is open you can also click it with the mouse.

## Camera and game

| Key | What it does |
| --- | --- |
| V | Cockpit or chase camera |
| Hold right mouse | Look round the cockpit without steering (in the chase camera, swing the camera round the ship). Let go to look ahead again ([Flying](Flying#looking-round)) |
| Esc | Pause. The pause screen has **Settings** ([Settings and Accessibility](Settings-and-Accessibility)) and the tow home ([FAQ](FAQ#im-lost-or-stuck-far-from-anywhere)) |
| F11 or Alt+Enter | Fullscreen or a window |
| Click | Capture the mouse again after it was let go (not while the nav computer is open) |
| F12 | Screenshot, saved as a picture in your screenshots folder ([FAQ](FAQ#where-are-my-saves-settings-and-screenshots)) |
| F3 | Debug overlay: frame rate, world seed, speed and position |

The game also pauses by itself when its window loses focus or lets go of the mouse.
